# S&S Group Creative Website

Responsive multi-page website using HTML, CSS and JavaScript.

## Files
- `index.html` — Home page
- `digital-connect.html` — Digital Connect services
- `hospitality.html` — Hospitality services
- `infra.html` — Infra services
- `technologies.html` — Technologies services
- `style.css` — Responsive design, colors, layouts and animations
- `script.js` — Mobile navigation, current year and reveal effects

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload all files to the root of your GitHub repository.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.

Images and Google Fonts load from external services, so an internet connection is required for those visual assets.
